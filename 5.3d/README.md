# SIT725 Task 4.2P – Cybersecurity Dashboard

## Overview

This project upgrades the Week 3 cybersecurity dashboard by integrating
MongoDB and moving cybersecurity threat data to the Express server.

The frontend requests the threat information from a REST API and dynamically
generates cybersecurity cards.

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- HTML
- CSS
- JavaScript
- Materialize CSS

## Original database fields

The database uses the following custom fields:

- threatName
- threatCategory
- severityLevel
- preventionMethod
- imagePath
- learnMoreLink
